# Feature Areas
Purpose: This lens groups end-user oriented Ringer capabilities.

## Features covered
- Manifest-driven execution and orchestration.
- Template kits and reusable run shapes.
- Multi-engine dispatch and routing behavior.
- Steering and decision policy support.
- HUD/dashboard visibility and artifact reporting.

## Directory layout
| Path | Role |
|---|---|
| `features/manifest-driven-execution.md` | Core run and task orchestration behavior |
| `features/engine-integrations.md` | Engine-specific behavior |
| `features/steering-and-routing.md` | Steering profile and rule lifecycle |
| `features/template-kits.md` | Kit-based reusable workflows |
| `features/artifacts-and-scoreboard.md` | Artifact export and scoring surfaces |
| `features/behavioral-hooks.md` | Nudge and hook behavior |
