# Workflows
Purpose: This lens documents repeatable repo workflows and operational sequences.

## Workflow pages
- `workflows/run-workflow.md`
- `workflows/repo-change-lifecycle.md`
- `workflows/kit-lifecycle.md`

## Common execution pattern
- Define: select or build manifest/kit
- Validate: lint
- Execute: run
- Verify: check results and scores
- Observe: dashboard/hud
- Ship artifact: artifact check and export
